# Hooks From a Winning Angle
**Use when:** an angle proved out and you need volume inside it. Run 01-angle-generation first.

```
[STORE BRIEF]
THE WINNING ANGLE (one sentence) + its metrics:
PLATFORM: <Meta / TikTok / Google / LinkedIn>
FORMAT: <static / UGC video / carousel / RSA>

Generate 12 hooks that all express THIS angle — do not drift to a different claim.
Spread them across execution styles: question, number, direct address, negative,
before/after, quote, demonstration, callout of the audience.

Per hook: the line, first-3-seconds visual direction (if video), and which sub-audience
it's sharpest for.

RULES:
- Platform-native length: TikTok spoken ≤ 12 words; Meta primary text ≤ 125 chars before
  the fold; RSA headlines ≤ 30 chars, and count them — a truncated headline is wasted spend.
- No claim beyond the brief's evidence. No implied health/income results.
- Flag any hook that would need a disclaimer to run.

SELF-CHECK: group the 12 by underlying promise. If they collapse into fewer than 4 groups,
you generated variations, not tests. Redo the thin groups.
```
