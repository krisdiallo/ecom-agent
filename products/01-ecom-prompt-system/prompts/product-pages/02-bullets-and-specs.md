# Benefit Bullets & Spec Block
**Use when:** the description is fine but the scannable parts are weak. Most buyers read only these.

```
[STORE BRIEF]
PRODUCT FACTS (materials, dimensions, weight, contents, care, compatibility, warranty):
THE 3 THINGS THAT LOSE THE SALE WHEN UNCLEAR:

Produce:
A) 5 bullets, each ≤14 words: <Benefit> — <the specific feature proving it>.
   Order them by what a buyer needs first, not by what's most impressive.
B) A spec table using ONLY facts above. Missing rows become [NEED: x] — do not estimate
   a dimension or weight. Wrong specs are the #1 cause of returns.
C) One "who this is not for" line. It raises conversion by pre-filtering bad fits and it
   is the single most trust-building sentence on most product pages.

SELF-CHECK: which bullets are features wearing a benefit costume? Rewrite them.
```
