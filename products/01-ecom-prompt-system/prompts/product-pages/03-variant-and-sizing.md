# Variant & Sizing Copy
**Use when:** returns are driven by "wrong size / not what I expected."

```
[STORE BRIEF]
VARIANTS (each option + how it differs functionally, not just visually):
SIZING DATA (measurements, fit notes, model reference, real return-reason data if you have it):
TOP 3 RETURN REASONS:

Produce:
A) A one-line decision rule per variant: "Choose X if you ___."
B) Sizing guidance written for someone who cannot try it on. Reference measurable things
   (chest in inches, a common object) not vibes ("true to size" is worthless without a baseline).
C) The single sentence to place next to the variant picker that would prevent the most returns.

RULES: Do not invent measurements. A guessed size chart is a refund with extra steps.
If the return data suggests the product itself is inconsistently sized, say so — copy
cannot fix a manufacturing variance and pretending otherwise costs more than it saves.
```
