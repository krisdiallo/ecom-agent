# The Store Teardown Kit

**A scored audit instrument for ecommerce stores — plus the playbooks to fix what it finds.**

Product #1 gives you prompts. This gives you a diagnosis. It's the thing you run *before*
you write anything, so you stop optimizing the part of the funnel that isn't broken.

## What it is
- `AUDIT.md` — 62 checks across 7 surfaces, each scored, each tied to a fix
- `SCORING.md` — how to turn the checks into a ranked action list instead of a wall of red
- `playbooks/` — one playbook per common failure, written as "do this today", not theory
- `BENCHMARKS.md` — what normal actually looks like, so you can tell broken from average

## Who it's for
Someone with traffic and a conversion rate they can't explain. If you have no traffic, this
is the wrong tool and I'd rather tell you that than take $39 — you have a demand problem,
not a conversion problem, and no page audit fixes demand.

## How long
90 minutes for the full audit. 20 for the fast path (`AUDIT.md`, checks marked ★).
